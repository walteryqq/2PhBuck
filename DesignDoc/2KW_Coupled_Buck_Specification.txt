1. 电源模块基本规格 (Power Stage Specifications)
--------------------------------------------------------------------------------
* 输入电压 (Vin):
  - 额定输入电压: 54.0 V
  - 输入电压范围: 40.0 V - 60.0 V

* 输出电压 (Vout / Vref):
  - 额定输出电压: 12.2 V
  - 稳态电压纹波: < 50 mV (纯开关纹波)

* 输出功率与电流:
  - 额定输出功率: 2.0 kW (2000 W)
  - 额定输出电流: 163.93 A (单相平均电流 81.97 A)
  - 半载输出电流: 81.97 A

* 开关特性:
  - 开关频率 (fs): 210.0 kHz
  - 拓扑结构: 两相交错并联 Buck (180度相移，由双相交错驱动降低总输入输出电流纹波)

2. 反向耦合电感设计参数 (Inversely Coupled Inductor - ICI)
--------------------------------------------------------------------------------
[IMAGE: coupled_buck_schematic.png]

* 磁芯与绕制设计:
  - 磁芯型号: 单个无中柱 EI 型金属粉芯 (TA130-μL)
  - 气隙分布: 分布式气隙设计，具备极高抗饱和能力

* 电性参数:
  - 单相自感 (L): 1.50 uH
  - 互感 (M): -1.05 uH
  - 耦合系数 (k): -0.70 (反向耦合)
  - 电感直流电阻 (Rdcr): 0.35 mΩ / 相

* 等效电感特性:
  - 暂态等效电感 (L_tr, 单相): L * (1 - |k|) = 0.45 uH
  - 暂态并联等效电感 (L_eq, 两相并联): L_tr / 2 = 0.225 uH
  - 稳态等效电感 (L_eq_steady): L * (1 - k^2) / (1 - |k| * D/(1-D)) = 0.96 uH (D = 0.226)

* 纹波减小与响应加速效应:
  - 相比无耦合独立电感 (L=1.5uH)，由于反向耦合磁通抵消，相电流稳态纹波减小达 44.2%
  - 暂态等效电感从 0.75 uH (独立电感并联) 降至 0.225 uH，极大地加速了暂态电流爬升率 (di/dt)

--------------------------------------------------------------------------------
3. 数字 MCU 控制器参数 (Digital MCU & Control Loop)
--------------------------------------------------------------------------------
* 控制模式:
  - 反馈模式: 电压控制模式 (Voltage Control Mode, 单环控制)

* 数字采样与开关频率比:
  - ADC 采样率 (f_sam): 100.0 kHz (采样周期 T_sam = 10.0 us)
  - 采样与开关频率比: 100kHz / 210kHz = 0.476 (在 100kHz 的 ADC 中断中完成闭环算法)

* 数字控制延时:
  - 计算与 PWM 更新延迟: 1.5 倍开关周期 (1.5 * T_sw = 7.14 us)
  - 开关周期等效延时: 1.5 个开关周期 (在 210kHz 下为 1.5 T_sw)

* 滤波与电容规格:
  - 输出滤波主电容 (C1): 5000.0 uF (ESR1 = 1.0 mΩ)
  - 输出滤波副电容 (C2): 100.0 uF (ESR2 = 0.3 mΩ)
  - 两组电容并联组成等效阻抗，极大地平抑了高频开关纹波与瞬态跌落

4. 闭环补偿器设计与环路指标 (PID Compensator & Stability Margins)
--------------------------------------------------------------------------------
[IMAGE: small_signal_diagram.png]

* 控制系统小信号数学框图说明:
  - 比较节点: 将设定参考电压扰动 v̂_ref(s) 与采样输出反馈扰动 v̂(s) 做差，产生误差信号 v̂_e(s) = v̂_ref(s) - v̂(s)。
  - 反馈控制器 H(s): 包含 PID 控制算法与数字计算/更新延迟，其传递函数为：
    H(s) = ( Kp + Ki_c/s + Kd*s/(1 + tau_d*s) ) * exp(-s * T_delay)
    其中，Kp = 0.05000 (比例增益)，Ki_c = 20.00 (连续积分增益，对应固件值 Ki = 0.0002)，Kd = 1.00e-6 (微分增益)，tau_d = 1.0 us (微分低通滤波时间常数)，T_delay = 1.5 * T_sw = 7.14 us (总数字计算与更新延迟)。
  - 调制与主电路 Gvd(s): 调制器增益 1/V_M = 1 已归一化并入控制器参数中。主电路控制-输出传递函数为：
    Gvd(s) = Vin * Z_p(s) / (Z_L(s) + Z_p(s))
    其中，Vin = 54.0 V，等效电感分支阻抗 Z_L(s) = s*Leq + Rdcr_eq，输出滤波与负载等效阻抗 Z_p(s) = Z_C(s) || Rload。

* 为什么可以用连续时间传递函数 H(s) 表达数字离散控制器？
  - 准连续域建模前提：采样频率 f_sam (100 kHz) 远高于闭环截止频率 fc (约 11.6 kHz)，满足 f_sam > 8*fc 频带约束。在此低频段内，数字化离散的高频非线性折返效应极弱，其动态特征高度逼近连续系统。
  - s与z域数学映射：利用 z = exp(s*T_sam) 的频率变换定义。在低频范围内由于 s*T_sam << 1，其一阶泰勒展开近似为 z ≈ 1 + s*T_sam。对于后向差分离散积分器 T_sam*z/(z-1)，代入展开后可化简为 1/s + T_sam ≈ 1/s。这在数学上证明了数字积分在环路带宽内与连续积分器的一致性。
  - 数字延迟的频域等效：MCU 采样及计算形成的 N 个周期延迟在 z 域对应 z^-N。代入频率映射后可严密表示为连续纯延迟项 exp(-s * N * T_sam) = exp(-s * T_delay)。它在 Bode 图上具有 1 (0dB) 的恒定增益，且精确引入 -w * T_delay 弧度的线性相位衰减，不存在近似误差。
  - 零阶保持器 (ZOH) 效应：ADC 与占空比更新的 ZOH 特性在频域等效于 [1 - exp(-s*T_sam)] / (s*T_sam)。在截止频率范围内，其幅值衰减很小，但其相频特性精确等效于额外引入了半个采样周期 (0.5 * T_sam) 的时间延迟。
  - 积分系数与总延时对齐：通过上述等效，数字 PID 中的离散积分系数 Ki 与连续增益 Ki_c 满足代数映射关系：Ki = Ki_c * T_sam = Ki_c / f_sam。数字系统的全部延迟（ZOH的 0.5*T_sam + MCU 计算与占空比更新的 1.0*T_sam）被折算为总的连续延迟 T_delay = 1.5 * T_sam（在 210kHz 开关下等效为 1.5 * T_sw）。由此在连续域下设计的截止频率和相位裕度，能高度吻合离散系统的真实响应。

* 离散 PID 补偿器差分方程实现 (MCU 中断执行代码):
  - 比例项: d_p[n] = Kp * e[n]
  - 积分项: d_i[n] = d_i[n-1] + Ki * e[n]  (Ki = 0.0002，对应 Ki_c = Ki * f_sam = 20.0)
  - 微分项 (带高频低通滤波): 
    d_d[n] = (tau_d / (tau_d + T_sam)) * d_d[n-1] + (Kd / (tau_d + T_sam)) * (e[n] - e[n-1])
  - 控制输出占空比: d[n] = d_p[n] + d_i[n] + d_d[n]

* 闭环稳定性边际指标 (半载/满载, Vin = 54V):
  - 环路穿越频率 (fc): 11.71 kHz / 11.63 kHz
  - 相位裕度 (Phase Margin): 48.1° / 49.5°
  - 系统稳定性: 稳定度良好 (PM 逼近 50°)，中低频无增益下陷，能够快速收敛负载扰动。

5. 仿真验证结果与暂态指标 (Transient & Ripple Simulation Verification)
--------------------------------------------------------------------------------
* 稳态电流与纹波指标 (满载 164A):
  - 稳态相电流平均值: 81.97 A
  - 稳态单相电流纹波 (Peak-to-Peak): 45.9 A (相比独立电感的 82.3 A 减小 44.2%)
  - 电流纹波降低幅度: 相比独立电感方案降低 44.2%

* 动态负载暂态响应规格 (包含以下两个典型工况):

  场景 1: 从 0% 电流突变至 60% 电流 (0 A -> 98.4 A, DCM 二极管仿真模式)
  - 最低电压跌落 (Undershoot): 0.60 V (最大跌落 4.92%)
  - 最大电压过冲 (Overshoot): 2.33 V (最大过冲 19.10%)
  - 恢复时间 (Settling Time, 至 1% 误差带): < 0.6 ms

  场景 2: 从 40% 电流突变至 100% 电流 (65.6 A -> 163.9 A, CCM 模式)
  - 最低电压跌落 (Undershoot): 0.66 V (最大跌落 5.41%，满足服务器电源 < 10% 跌落的规范)
  - 最大电压过冲 (Overshoot): 0.58 V (最大过冲 4.77%)
  - 恢复时间 (Settling Time, 至 1% 误差带): < 0.5 ms

  - 对比测试: 在上述两个场景下，无耦合独立电感系统由于极点过低且相位掉落极快，容易发散失稳;
             而反向耦合电感系统由于暂态等效电感大幅降低，结合非零 Kd 微分项，有效保障了闭环稳定性与快速的暂态收敛。

--------------------------------------------------------------------------------
6. 输出阻抗频率特性 (Output Impedance Specifications)
--------------------------------------------------------------------------------
* 输出阻抗压制指标:
  - 直流闭环输出阻抗 (f = 10Hz): 0.01 mΩ (由于积分作用被强烈压制)
  - 穿越频率处阻抗 (fc = 11.63 kHz): 4.08 mΩ (无阻抗峰值隆起，阻尼良好)
  - 高频渐进阻抗 (f > 100 kHz): 0.89 mΩ (受限于输出电容 ESR)
  - 阻抗隆起 (Peaking): 0.0 dB (极佳的相位裕度，有效抑制暂态电压过冲和铃流振荡)
